# 扫描与清理交互调整

- 首页改为“扫描与清理”：实际系统状态 → 自动扫描状态 → 可处理项目 → 勾选 → 一键移至系统废纸篓。
- 启动后检查常见本机目录和已有授权范围；额外目录授权保留为可选入口。
- 默认不勾选项目。仅安全核心核实为可处理的项目显示勾选框；重要、未知、未完整扫描、应用正在使用或身份变化的项目显示保留原因。
- 每一项展示完整路径、文件大小、分配空间、用途、风险和 Finder 定位；保留详细说明。
- 主按钮明确标为“一键移至废纸篓”，显示选择数量和可释放空间估算上限，并说明移入废纸篓通常不会立即释放空间。
- 首页显示处理反馈，扫描或安全核实期间不允许处理。
- 结果使用懒加载并限制展示数量，支持按名称和路径搜索；所有数字来自实际扫描和安全评估。
- 详细扫描、应用诊断、使用说明保留为次级页面。移除“第一阶段只读，后续才提供处理”的过期界面文字；长期历史监控仍如实说明待开发。

界面调整自身不执行文件写入；所有清理操作通过状态层调用安全核心，并且只处理用户选中的项目。
