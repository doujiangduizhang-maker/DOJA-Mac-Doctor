# 勾选处理的安全测试

清理测试使用本次运行自己创建的 UUID 小目录中的真实文件，扫描结果来自文件系统。测试中的“废纸篓”是注入的同一隔离目录内移动操作，不会调用用户的系统废纸篓，不会移走用户文件。每个测试结束只移除自己创建的隔离夹具。

## 独立验证入口

```sh
.build/debug/doctor-scan --cleanup-self-check
```

默认夹具在项目所在外置卷。若外置卷不支持硬链接、符号链接或 POSIX 权限，相关检查明确显示未执行。内部 APFS 实测需显式选择小夹具：

```sh
.build/debug/doctor-scan --cleanup-self-check \
  --fixture-root /private/tmp/doja-doctor-small-fixtures \
  --allow-small-internal-fixtures
```

每个场景普通文件写入预算不超过 256 KiB，内部卷每个场景实际分配检查不超过 512 KiB，场景按顺序运行并及时移除自己的夹具。不得把场景根路径改为用户数据目录，也不得注入会永久删除源目录的回调。

## 检查内容

- 完整扫描的已知缓存可以勾选；未选择目录保持原样；准备计划只读。
- 隔离移动后完整核对实际文件字节，并移回原位验证可恢复。
- 黄色、红色、不完整、取消扫描、未知普通文件、媒体、会话和代码不能被强制选中绕过保护。
- 当前授权范围之外及整个 Codex Application Support 拒绝处理。
- 重复路径和重叠授权不会重复处理。
- 同大小、同修改时间的文件替换仍能使已确认计划失效。
- 确认后插入微小隐藏代码，以及修改小缓存文件，会阻止过期计划。
- Codex 在确认后重新启动会阻止执行。
- 单项移动失败不会抹去其他项的独立结果；失败项恢复原位。
- 恢复遇到原路径被重建时，不覆盖新文件；旧数据保留在明确返回的恢复路径。
- 符号链接祖先、范围外硬链接和只读父目录拒绝处理；不支持的文件系统特性明确跳过。

## XCTest

完整 Xcode 提供 XCTest 时，`Tests/DoctorCoreTests/CleanupTests.swift` 可随 `swift test` 运行。仅安装 Command Line Tools 的环境使用上面的独立验证入口。构建沿用 `TEST-PLAN.md` 的外置卷编译缓存配置。

## 物理空间说明

测试的移动与恢复不宣称释放物理空间。APFS 克隆、快照、硬链接、打开的文件都影响真正释放量；移至废纸篓本身也不表示立即释放。路径逻辑大小与文件分配大小仅核对处理范围，实际剩余空间读数是系统瞬时值。
