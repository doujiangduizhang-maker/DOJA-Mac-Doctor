## 安全与空间口径

勾选框只出现在固定 Codex 缓存叶目录全部通过核实且 Codex 已退出的情况。黄色、红色、未知、未完整覆盖与仍被使用的缓存没有勾选框。未勾选不会移动；执行按钮就是对当前具体选择的确认，不额外弹出重复确认。

选择绑定原清单，处理时不接受更新后的内容作为旧选择。每项前再次核对元数据、父路径身份、完整清单及运行状态。过期、变化或无法核实时保留并解释；父目录恢复采取排他移动，不覆盖新文件。

只使用系统废纸篓，禁止永久删除、管理员提权、清空废纸篓、整体清理 Application Support。显示移入结果与真实系统容量，不把文件大小或上限估算称为已经释放的空间。

安全暂存名称包含 `DOJA Mac Doctor Recovery`、原缓存名称和 UUID。Finder 恢复后不保证自动回到原路径或名称；界面处理记录显示原完整路径、确切废纸篓项及恢复位置，并说明核对归位。普通退出不会中断正在完成的移动，强制结束仍可能留下可见恢复目录，下一次扫描会保留并提示。
