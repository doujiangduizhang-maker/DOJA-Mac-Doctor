## 保留限制

应用退出或休眠期间没有连续观测，较长间断会断开趋势和异常比较。不会安装登录后台服务；关闭主窗口仍可从菜单栏运行，完全退出后停止采样。

重点目录共享每轮约 5 秒元数据预算，每个最多 20,000 个文件，至少冷却 5 分钟；在系统调用阻塞时不能保证硬墙钟时限。大目录可能一直待完整核对。目录前后观测必须同范围、完整、同卷且足够接近事件端点，否则明确原因待确认，不给出虚构的归因。

清理当前仅开放固定 Codex 缓存子目录的严格核实路径。日志、崩溃报告、影视缓存、代理、未知副本、工程、素材、配置和会话保留。移入废纸篓通常不释放空间，应用不自动清空。更多已验证缓存格式可以另行扩展。

扫描计算和保护检查先使用全量数据。完成诊断、目录监控基线与清理清单后，常驻结果裁成最多 2000 个最大目录及根目录、1000 个覆盖问题，保留全部类型汇总、文件榜单、真实总量与全量覆盖计数，降低后台内存。未保留细项不代表不存在；目录增长只比较双方保留且完整的记录。清理准备仍使用裁剪前的全量覆盖与保护证据。

详细规则见 [历史记录](MONITORING.md)、[目录事件](MONITORING-DIRECTORIES.md) 与 [清理安全](CLEANUP-SAFETY.md)。
